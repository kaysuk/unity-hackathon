# Черновой звук «Братьев Карамазовых»

[Послушать монтаж, 32 секунды](temple-sound-preview.mp3). В начале Иван переходит с земли на камень. На 0:07 охрана замечает его, на 0:09 слышна ответная очередь. С 0:15 звучат бумага, ключ и решётка. С 0:22 можно сравнить две атаки Ангела. Монтаж собран из игровых клипов вручную. В игре расстояние, положение камеры и акустика комнаты меняют баланс.

| Событие | Что слышно | Клипы для замены |
| --- | --- | --- |
| Ходьба, бег, присед, разворот, приземление | Четыре чередующихся удара подошвы на каждом покрытии. На земле слышно зерно под ногой, на камне заметнее удар пятки. Одежда звучит отдельным слоем. При движении в приседе оба слоя тише. | `EarthLeft1…EarthRight2`, `StoneLeft1…StoneRight2`, `Cloth`, `Scuff`, `Land` |
| Достать оружие, прицелиться, убрать, сменить магазин | Трение кобуры, движение ткани, два разных металлических щелчка. Если перезарядка сорвалась, завершающий щелчок отсутствует. У пустого пистолета слышен сухой спуск. | `Draw`, `Stow`, `Cloth`, `MagazineOut`, `MagazineIn`, `DryFire` |
| Стрельба и попадания | Одиночный выстрел Ивана и отдельная запись винтовки. Каждый выстрел очереди запускает сама охрана. Попадание в стену даёт короткую осыпь в точке удара. | `Pistol`, `Rifle shot`, `WallHit` |
| Захват сзади, ранение и падение | Рывок ткани в начале захвата, короткая голосовая реакция при уроне, затем тяжёлый удар тела при гибели. | `Grapple`, `BodyHit`, `BodyFall` |

Сигнал обнаружения сохраняет исходную запись проекта «SWAT alert». Музыка ритуала собрана для этой версии из низкого барабанного пульса, затухающего металлического созвучия и записанного фоли.

## Замена на заказную озвучку

Основной банк находится в `Assets/Resources/GameAudio`. Записи винтовки, сигнала обнаружения и архивного храповика лежат в `Assets/Audio`. Для замены достаточно обновить содержимое одноимённого файла и сохранить его Unity `.meta`. Игровые события и ссылки префабов продолжат работать.

Эффекты записаны в моно, музыка — в стерео. Громкость всего проекта регулирует ползунок главного меню. У мировых звуков есть позиция и затухание. В храме используется короткая каменная реверберация, в ритуальном зале — отражения большего помещения. Музыка и звуки интерфейса обходят эти зоны.
