# Озвучка Ивана, Дмитрия и медсестры

В [каталоге реплик](speech-catalog.tsv) можно найти запись по сцене, смыслу, актёру или исходному имени. Каждая строка указывает путь к WAV в проекте, момент использования, условие ветки и результат проверки звука. В наборе 179 исходных WAV общей длительностью 13 минут 13 секунд.

| Префикс | Голос | Исходных записей |
| --- | --- | ---: |
| ON | Медсестра в телефонном разговоре в офисе | 3 |
| OD | Дмитрий, включая рассказчика в плохой концовке | 25 |
| OI | Иван, включая монологи, игровые реплики и дыхание | 151 |

Имя мастера состоит из префикса и номера, например `OD.04.wav`. Игровой файл добавляет описание, например `OD.04.protests_office_arrest.wav`. Поле `received_filename` хранит имя из переданного набора. Идентификатор `cue_id` связывает реплику с игровым событием.

## Где искать запись

| Папка относительно `Assets/Resources/speech` | Содержание |
| --- | --- |
| `cut-scenes` | Вступление, два культиста, бегство, офис, превращение и три финала. Подпапки соответствуют этапам сюжета. |
| `scenes` | Реплики с единственным игровым поводом. Здесь лежат осмотр шкафа при первом посещении, возвращение к оцеплению, спуск в церковь, документы храма и реакции на разрушение алтарей. |
| `ivan/phrases` | Короткие игровые фразы для повторяющихся действий, включая нехватку патронов и получение урона. |
| `ivan/sounds` | Дыхание и короткие вокальные реакции. |

Четыре альтернативных исполнения лежат в подпапках `takes` дерева `AssetSources/speech`. В подпапках `review` лежат 19 фрагментов для прослушивания перед назначением. В том числе это звуки с неясным действием и вероятные внесюжетные дубли. Основной голос угрозы Дмитрия после пощады — `OD.20`. Вариант актёра Ивана `OI.46` сохранён в `takes`.

Из исходного набора 125 уникальных WAV перечислены в [манифесте событий Unity](../../Assets/Resources/SpeechCues.json), ещё 34 доступны в [резерве озвучки](../../AssetSources/speech/reserve). Столбец `runtime_event` показывает фактические ключи манифеста или статус «резерв», «дубль», «на проверку».

## Как привязаны реплики

В `story_stage` указаны этапы от 1 до 11. Значение 0 обозначает общий игровой звук. Для сюжетных фраз `page` указывает номер рисунка, а `playback_positions` — номер реплики внутри этой страницы, начиная с единицы. Для игровых фраз предназначено поле `event`. Ветки `alive` и `dead` относятся к выбору в офисе. Имена `bad`, `good` и `best` совпадают с именами вариантов финальных рисунков. Папка `common` содержит общую реплику начала финала.

В храме семь архивных документов. D01–D06 лежат по одному в комнатах 1–6. D07 находится за решёткой в комнате 7.2. Она открывается, когда игрок выровнял шесть дисков и расставил шесть камней по правильным гнёздам. Если D07 взят раньше другой записки, полную запись можно прочитать после сбора комплекта, в том числе при входе в ритуальный зал.

Пощада Дмитрия всегда запускает `bad`. Если Иван убил Дмитрия, при 0–6 документах запускается `good`, а при всех семи — `best`. Лист «Расчёт шести печатей» в комнате 7.1 служит подсказкой к загадке и учитывается в инвентаре отдельно.

Вступление `OI.01` остаётся одной записью. На кадрах 7–14 используются последовательные диапазоны одного WAV с границами в паузах между предложениями. Для этой записи после символа `#` в каталоге указан диапазон отсчётов исходника. Конечный отсчёт входит в следующий диапазон. На рисунках 5–6 слышен самолёт.

Две монтажные склейки разделены по исходным границам актёрских клипов. `OI.82` дал три отдельных события для уже осмотренного объекта, пустого магазина и малого остатка патронов. `OI.86` дал две фразы про ненужный предмет и поиск другого способа. Порядковый номер фрагмента стоит после номера мастера. Склейка PCM этих частей в исходном порядке побайтово восстанавливает каждый из двух мастеров.

В комнате 7.2 подземного храма (`temple_v2`) используются ещё три записи из отдельного набора. Они лежат в `scenes/08-temple/room-7-2` и звучат через канал «Диалоги».

| Запись | Момент воспроизведения |
| --- | --- |
| `gladivir_riddle.wav` | Первый вход Ивана из архива в вестибюль за потайной стеной. |
| `gladivir_riddle_remind.wav` | Действие «Повторить загадку» у каменного стола со свечами в вестибюле. Доступно до открытия решётки. |
| `gladivir_ecourage.wav` | Все шесть дисков выровнены. Начинают подниматься гнёзда для камней. |

## Проверка записей

Все 179 файлов успешно декодировались до последнего отсчёта. Проверены размеры блоков RIFF, целостность фреймов PCM, длительность, амплитуда и средний уровень сигнала. Каналы всех записей моно. У Ивана 149 мастеров в 48 кГц / 24 бит и два в 48 кГц / 16 бит. У Дмитрия и медсестры 28 мастеров в 44,1 кГц / 16 бит. Из этих мастеров в проекте 182 WAV, включая 159 основных, четыре альтернативы и 19 файлов для проверки. Формат исходного PCM и частота дискретизации сохранены.

| Наблюдение | Что проверять при монтаже |
| --- | --- |
| 16 исходников со средним уровнем ниже −40 dBFS | Среди них есть намеренно тихое дыхание. В `audio_quality_ru` и `source_rms_dBFS` отмечены конкретные записи. Уровень указан для целого исходника вместе с паузами. |
| Две записи с длинным вступительным отступом | У `t04c01` речь начинается примерно через 2,32 с, у `t11c05` заметная активность начинается примерно через 2,54 с. |
| Возможный перегруз до обработки | В монтажных заметках отмечены `t05c11` (`OI.34`), `t05c14` (`OI.37`) и вторая часть `t12c12` (`OI.112`, исходный фрагмент `t12_c13`). Текущие WAV успешно декодируются. Для первых двух реплик стоит прослушать самые громкие слоги перед финальным сведением. |
| Короткий фрагмент после боя | `t08c05` (`OI.61`) содержит 8 538 отсчётов при 48 кГц, ровно 0,177875 с. Смысл звука остаётся неясным. Файл находится в `review`. |

Атрибуция опирается на текст сцен, рисунки, монтажный индекс Ивана и повторное распознавание русской речи по отдельным файлам. Для невербальных фрагментов дополнительно проверены акустические классы дыхания, вздоха, кашля и голоса. В поле `source_decodes` указана техническая целостность WAV. Поля `audio_quality_ru` и `context_confidence` помогают отдельно оценить качество сигнала и уверенность в назначении реплики.
